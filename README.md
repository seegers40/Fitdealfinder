# FitDealFinder

FitDealFinder is een fitness deals- en vergelijkingswebsite voor producten rond cut, bulk en lean-bulk.

## Stack

- Cloudflare Workers
- Cloudflare D1
- Cloudflare Workers Assets
- TypeScript
- HTML/CSS/JavaScript
- Awin productfeed
- Optionele AI-integratie

Render, Neon en Hyperdrive zijn niet nodig.
